НОГАЙ ТИЛ — 8 КЛАСС. Первая версия браузерной читалки.

ЗАПУСК
1. Распакуйте ZIP полностью в отдельную папку.
2. Windows: запустите START_WINDOWS.bat (нужен Python 3).
   macOS/Linux: запустите START_MAC_LINUX.sh (нужен Python 3).
3. В браузере откройте http://localhost:8765

Страницы учебника — локальные изображения из предоставленного PDF.
Интернет для чтения не требуется.

РЕАЛИЗОВАНО
- Все 154 страницы, книжный разворот, одна страница, навигация, масштаб.
- Оглавление (первоначальная структура, подлежит расширению).
- Закладки, заметки, точечные заметки на страницах (через Настройки).
- Поиск по тексту PDF, полный экран.
- Модальное демонстрационное задание на странице 5.
- Демонстрация аудиозадания на странице 32 без аудиофайла.

ОГРАНИЧЕНИЯ
- Тексты упражнений и проверка ответов пока не наполнены; пример не оценивает знания.
- Аудиофайлы не приложены к PDF.
- Перелистывание имеет лёгкую анимацию, но ещё не физическую 3D-анимацию загиба листа.
- Закладки и заметки хранятся только в localStorage данного браузера.
- Для поиска требуется запуск через локальный сервер, а не file://.

VERSION 1.5 - StPageFlip
The page-turning engine is StPageFlip 2.0.7 (MIT license).
This version loads the engine from cdn.jsdelivr.net on startup, so an internet connection is required to display the book. The textbook pages themselves are local.
Source: https://github.com/Nodlik/StPageFlip
